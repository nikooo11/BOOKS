# Book Notes · The Influences of Money

Deep-dive study guides, one folder per book. Each guide covers every chapter in order and includes:

- the author's argument in plain language
- verbatim key quotes with page numbers, checked against the source
- concepts and the original experiments
- links between chapters
- real-world examples from markets, investing and money
- takeaways and "how to apply it" sections for investing, persuasion, content and clear thinking

Each book folder contains:

| File | What it is |
|---|---|
| `<Book>-Study-Guide.pdf` | Designed, print-ready guide |
| `<Book>-Study-Guide.md` | The same guide in Markdown (readable on GitHub) |
| `<Book>-Quotes.md` | Every quoted line with page number and verification status |
